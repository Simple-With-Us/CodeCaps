What It Reads

CodeCaps reuses supported apps' existing local sign-ins for their available usage data.  You do not enter provider API keys into CodeCaps.  A missing or unreadable source is shown as unavailable.

  • Claude — quota windows (5-hour and weekly), read from ~/.claude/.credentials.json or the Keychain.
  • Codex — rate-limit windows, read from ~/.codex/auth.json.
  • Antigravity — pooled Gemini and Third-Party quota, read via the antigravity-usage CLI and Antigravity's own language server.
  • Cursor — included-plan usage, read from Cursor.app's local session database.
  • Grok CLI — billing and credits, read via Grok's CLI proxy from ~/.grok/auth.json.
  • Grok Bot — weekly usage, read via Cursor's dashboard service, from that same session database.
  • MiniMax — per-model and weekly remaining quota, read from ~/.mmx/config.json.

The first time a freshly installed CodeCaps needs Claude Code’s Keychain item, macOS asks whether to let it through.  The login Keychain grants access per app, so a brand new CodeCaps is a brand new app to it, and Claude can read as signed out while Claude Code is signed in.  Press Allow Access To Claude Code on the Claude row in Settings → Sources & Fleet and choose Always Allow: it is asked once, it is a read, and CodeCaps never writes to or removes Claude Code’s saved login.

Fleet Push And Pull

CodeCaps can push this Mac's quota readings to a collector you configure and pull readings from other configured Macs into the same view.  Both connections are off by default.  Enabling either one makes requests to your chosen endpoint; its ingest or read token is stored in the macOS Keychain.

How The Headline Number Is Chosen

Each supported source reports its own usage measure and reset window; a quota percentage is not a bill or subscription charge.  A collapsed row shows the fresh window with the lowest remaining percentage and that window's reset time.  Menu Bar → Displayed Quota lets you choose the lowest active quota, the lowest quota overall, or a named window.  Console's Next Reset tile shows the soonest reset among fresh windows.

Is This For You?

Use CodeCaps for a local view of supported AI plan windows.  If you run a collector, you can also share this Mac's readings and see readings from other configured Macs in one view.
